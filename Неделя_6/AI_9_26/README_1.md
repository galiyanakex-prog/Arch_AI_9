> **Неделя 6, День 26.** Запуск локальной LLM и проверка её работы.

## Что сделано

Установлена и запущена локальная генеративная модель **Qwen2.5-Coder-3B-Instruct-Distill-Qwen3-Coder-Next-abliterated** (квантование Q6_K, ~2,5 ГБ) через **LM Studio**. Модель доступна по HTTP API на `127.0.0.1:1234` и отвечает на запросы.

---

## Как запустить

### 1. Поднять LM Studio

```bash
# Запустить HTTP-сервер LM Studio
~/.lmstudio/bin/lms server start

# Загрузить боевую модель в память
~/.lmstudio/bin/lms load mradermacher/Qwen2.5-Coder-3B-Instruct-Distill-Qwen3-Coder-Next-abliterated-GGUF:Qwen2.5-Coder-3B-Instruct-Distill-Qwen3-Coder-Next-abliterated.Q6_K.gguf --gpu 0 --context-length 8192

# Проверить, что модель загружена
~/.lmstudio/bin/lms ps
```

Сервер будет слушать `127.0.0.1:1234`.

### 2. Проверить, что модель отвечает

```bash
# Smoke-запрос (простой)
curl -s http://127.0.0.1:1234/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mradermacher/Qwen2.5-Coder-3B-Instruct-Distill-Qwen3-Coder-Next-abliterated-GGUF:Qwen2.5-Coder-3B-Instruct-Distill-Qwen3-Coder-Next-abliterated.Q6_K.gguf",
    "messages": [{"role": "user", "content": "Скажи: ок"}],
    "max_tokens": 10
  }'
```

Ожидаемый ответ: `"ok"`.

## Три запроса разной сложности

### Запрос 1 — простой (smoke)


**Результат:** модель вернула `"ok"`. Время ответа — ~50 мс.

## Как модель используется в проекте

Локальная LLM — один из провайдеров наряду с облачной моделью (`stepfun/step-3.5-flash`). Переключение между ними — командой `/model use <id>` в REPL или флагом `--model <id>` при запуске.

Локальная модель используется для:
- **Приватных запросов** — данные не уходят в облако
- **Работы без интернета** — агент продолжает отвечать
- **Субагентов** — вспомогательные CLI-сессии на локальной модели
- **Локального RAG** — генерация ответов по индексированным документам без обращения к облаку
